# Código de Conduta

## Nosso compromisso

No interesse de promover um ambiente aberto e acolhedor, os participantes deste projeto se
comprometem a tornar a participação uma experiência livre de assédio para todos,
independentemente de idade, aparência, deficiência, etnia, identidade de gênero, nível de
experiência, nacionalidade, religião ou orientação sexual.

## Nossos padrões

Exemplos de comportamento que contribuem para um ambiente positivo:

- Usar linguagem acolhedora e inclusiva.
- Respeitar pontos de vista e experiências diferentes.
- Aceitar críticas construtivas com elegância.
- Focar no que é melhor para a comunidade.

Comportamentos inaceitáveis incluem assédio de qualquer forma, comentários ofensivos e ataques
pessoais ou políticos.

## Aplicação

Casos de comportamento abusivo podem ser reportados aos mantenedores do projeto por meio de uma
_issue_ privada ou dos contatos indicados em [SECURITY.md](SECURITY.md). Todas as queixas serão
analisadas e investigadas.

Este código é adaptado do [Contributor Covenant](https://www.contributor-covenant.org), versão
2.1.
